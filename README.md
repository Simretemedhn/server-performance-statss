# Server Performance Stats

A Bash script that monitors basic Linux server performance and displays
important system statistics directly in the terminal.

## Features

The script reports:

- Operating system
- Kernel version
- Hostname
- System uptime
- Load average
- Total CPU usage
- Total memory
- Used memory
- Available memory
- Memory usage percentage
- Total disk space
- Used disk space
- Available disk space
- Disk usage percentage
- Top 5 processes by CPU usage
- Top 5 processes by memory usage
- Logged-in users

## Requirements

- Linux operating system
- Bash
- Standard Linux utilities

The project can also be run inside WSL2 with Ubuntu on Windows.

## Installation
